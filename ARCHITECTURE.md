# Архитектура MailCheque

## Общая структура

```
MailCheque/
├── main.py                 # Точка входа в приложение
├── src/                    # Основной исходный код
│   ├── app.py             # Главный модуль приложения
│   ├── config/            # Модуль конфигурации
│   │   └── settings.py    # Управление настройками
│   ├── myEmail/             # Модуль работы с почтой
│   │   └── imap_client.py # IMAP клиент для Yandex
│   ├── parser/            # Модуль парсинга
│   │   └── receipt_parser.py # Извлечение данных чеков
│   ├── gui/               # Модуль графического интерфейса
│   │   └── main_window.py # Главное окно и диалоги
│   └── logging/           # Модуль логирования
│       └── logger.py      # JSON логгер
├── tests/                 # Модульные тесты
│   ├── test_*.py          # Тесты для каждого модуля
│   └── run_tests.py       # Запуск тестов
├── build.py               # Скрипт сборки в .exe
├── config.json            # Файл конфигурации
└── logs.json              # Файл логов
```

## Компоненты системы

### 1. Главный модуль (app.py)
**Ответственность**: Координация всех компонентов, управление жизненным циклом

**Основные классы**:
- `MailChequeApp` - главный класс приложения

**Ключевые функции**:
- Инициализация всех компонентов
- Обработка событий GUI
- Управление многопоточностью
- Координация поиска чеков

### 2. Конфигурация (config/settings.py)
**Ответственность**: Управление настройками приложения

**Основные классы**:
- `Config` - класс для работы с конфигурацией

**Ключевые функции**:
- Сохранение/загрузка настроек
- Валидация параметров
- Значения по умолчанию
- Работа с датами

### 3. IMAP клиент (email/imap_client.py)
**Ответственность**: Подключение к почте Yandex и получение писем

**Основные классы**:
- `IMAPClient` - IMAP клиент

**Ключевые функции**:
- SSL подключение к серверу
- Аутентификация
- Поиск писем по датам
- Извлечение содержимого писем
- Контекстный менеджер

### 4. Парсер чеков (parser/receipt_parser.py)
**Ответственность**: Анализ писем и извлечение данных чеков

**Основные классы**:
- `ReceiptParser` - парсер чеков
- `Receipt` - структура данных чека

**Ключевые функции**:
- Определение писем с чеками
- Извлечение сумм денег
- Парсинг дат
- Получение названий чеков
- Сортировка результатов

### 5. GUI (gui/main_window.py)
**Ответственность**: Пользовательский интерфейс

**Основные классы**:
- `MainWindow` - главное окно
- `SettingsWindow` - окно настроек
- `DateRangeDialog` - диалог выбора периода

**Ключевые функции**:
- Отображение результатов в таблице
- Настройка параметров подключения
- Выбор периода поиска
- Обработка ошибок

### 6. Логирование (logging/logger.py)
**Ответственность**: Ведение журнала операций

**Основные классы**:
- `JSONLogger` - JSON логгер

**Ключевые функции**:
- Запись логов в JSON
- Статистика операций
- Экспорт логов
- Очистка старых записей

## Поток данных

### 1. Инициализация
```
main.py → app.py → Config + GUI + Logger
```

### 2. Настройка
```
GUI → SettingsWindow → Config.save_config()
```

### 3. Поиск чеков
```
GUI → app._search_receipts() → Thread
Thread → IMAPClient → ReceiptParser → GUI.show_receipts()
Thread → Logger.log_request()
```

### 4. Обработка ошибок
```
Any Component → Exception → GUI.show_error()
```

## Архитектурные принципы

### 1. Разделение ответственности
- Каждый модуль отвечает за свою область
- Четкие интерфейсы между компонентами
- Минимальные зависимости

### 2. Многопоточность
- GUI остается отзывчивым
- Долгие операции в отдельных потоках
- Безопасное обновление GUI

### 3. Обработка ошибок
- Graceful degradation
- Информативные сообщения пользователю
- Логирование всех ошибок

### 4. Конфигурируемость
- Все настройки в одном месте
- Сохранение между запусками
- Значения по умолчанию

### 5. Тестируемость
- Мок-объекты для внешних зависимостей
- Изолированные тесты модулей
- Покрытие основных сценариев

## Расширяемость

### Добавление новых источников почты
1. Создать новый класс в `myEmail/`
2. Наследовать от базового интерфейса
3. Реализовать методы подключения и поиска

### Добавление новых форматов чеков
1. Расширить `ReceiptParser`
2. Добавить новые паттерны распознавания
3. Обновить тесты

### Добавление экспорта результатов
1. Создать новый модуль `export/`
2. Реализовать различные форматы
3. Добавить в GUI кнопки экспорта
