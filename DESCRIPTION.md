# MailCheque - Email Receipt Parser

MailCheque is a desktop application that automatically searches and extracts receipts from your email inbox via IMAP protocol. The application connects to mail servers (Mail.ru, Yandex, etc.), scans emails for digital receipts from various payment systems (YooMoney, Taxcom, Sberbank), and generates detailed reports with transaction summaries. Built with Python and Tkinter, it features password encryption for secure credential storage and can be compiled into a standalone Windows executable for easy distribution.
