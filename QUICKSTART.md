# Быстрый старт MailCheque

## 🚀 Запуск готового приложения

### 1. Сборка .exe файла
```bash
# Установка зависимостей
pip install pyinstaller

# Сборка приложения
python build.py
```

### 2. Запуск
```bash
# Из исходного кода
python main.py

# Или готовый .exe
dist/MailCheque.exe
```

## ⚙️ Первоначальная настройка

### 1. Настройка Yandex
1. Войдите в [настройки почты Yandex](https://mail.yandex.ru)
2. Включите **IMAP доступ**
3. Создайте **пароль для приложений**:
   - Безопасность → Пароли для приложений
   - Создать пароль → Почта
   - Скопируйте пароль

### 2. Настройка приложения
1. Запустите MailCheque
2. Нажмите **"⚙ Настройки"**
3. Заполните:
   - **Email**: ваш@yandex.ru
   - **Пароль**: пароль для приложений (НЕ основной!)
   - **Папка**: INBOX
4. Нажмите **"Сохранить"**

## 🔧 Разработка

### Структура проекта
```
MailCheque/
├── src/                    # Исходный код
│   ├── app.py             # Главный модуль
│   ├── config/            # Конфигурация
│   ├── email/             # IMAP клиент
│   ├── parser/            # Парсер чеков
│   ├── gui/               # Графический интерфейс
│   └── logging/           # Логирование
├── tests/                 # Тесты
├── main.py                # Точка входа
└── build.py               # Сборка
```

### Основные модули
- **Config** - управление настройками
- **IMAPClient** - подключение к почте
- **ReceiptParser** - извлечение данных чеков
- **MainWindow** - графический интерфейс
- **JSONLogger** - ведение логов

### Добавление нового функционала
1. Создайте модуль в `src/`
2. Напишите тесты в `tests/`
3. Обновите `app.py`
4. Добавьте GUI элементы в `main_window.py`

## 🐛 Устранение неполадок

### Частые проблемы

#### ❌ "Ошибка аутентификации"
- Проверьте email и пароль
- Используйте пароль для приложений
- Убедитесь, что IMAP включен

#### ❌ "Не удалось подключиться"
- Проверьте интернет
- Отключите файрвол
- Проверьте IMAP сервер

#### ❌ "Не найдены чеки"
- Проверьте папку
- Расширьте период
- Убедитесь, что есть письма

### Логи
- Файл: `logs.json`
- Содержит: время, параметры, результаты, ошибки
- Формат: JSON для анализа

## 📊 Мониторинг

### Статистика использования
```python
from src.logging.logger import JSONLogger

logger = JSONLogger()
stats = logger.get_statistics()
print(f"Всего запросов: {stats['total_requests']}")
print(f"Успешных: {stats['successful_requests']}")
print(f"Найдено чеков: {stats['total_receipts']}")
print(f"Общая сумма: {stats['total_amount']}")
```

### Экспорт логов
```python
# Экспорт в CSV
logger.export_logs("logs_export.csv", "csv")

# Экспорт в JSON
logger.export_logs("logs_export.json", "json")
```
