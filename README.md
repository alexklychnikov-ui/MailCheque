# MailCheque - Поиск чеков в почте Mail.ru

Windows-приложение для автоматического поиска и анализа чеков в почтовом ящике Mail.ru.

## Возможности

- 🔍 **Поиск чеков** - Автоматический поиск писем с чеками за указанный период
- 📂 **Умный поиск по папкам** - Автоматическая проверка системных папок Mail.ru (Чеки, Покупки и др.)
- 📊 **Анализ данных** - Извлечение наименования, даты и суммы из чеков
- 💾 **Сохранение настроек** - Запоминание email, пароля и папки между запусками
- 🔐 **Безопасность** - Шифрование паролей локально на компьютере
- 📈 **Табличный вывод** - Удобное отображение результатов в виде таблицы
- 📋 **Логирование** - Ведение журнала всех запросов в формате JSON
- 🎯 **Итоговая сумма** - Автоматический подсчет общей суммы найденных чеков
- ✨ **Удаление дубликатов** - Автоматическое исключение повторяющихся чеков

## Требования

- Windows 10/11
- Python 3.7+ (для разработки)
- Аккаунт Mail.ru с включенным IMAP

## Настройка IMAP в Mail.ru

Перед использованием приложения необходимо настроить IMAP доступ в вашем аккаунте Mail.ru:

1. Войдите в настройки почты Mail.ru
2. Перейдите в раздел "Почтовые программы" (или "Пароль и безопасность")
3. Включите IMAP доступ
4. Создайте пароль для приложений (НЕ используйте основной пароль!)

📖 **Подробная инструкция**: см. файл [MAILRU_SETUP.md](MAILRU_SETUP.md)

## Использование

### Первый запуск

1. Запустите приложение
2. Нажмите кнопку "⚙ Настройки"
3. Заполните данные:
   - **Email**: ваш email на Mail.ru (например, `user@mail.ru`)
   - **Пароль**: пароль для приложений (НЕ основной пароль!)
   - **Папка**: оставьте `INBOX` — приложение автоматически проверит все системные папки
   - **IMAP сервер**: imap.mail.ru
   - **IMAP порт**: 993

💡 **Совет**: Приложение автоматически ищет чеки в следующих папках Mail.ru:
- INBOX (входящие)
- Чеки, Покупки, Счета и чеки
- Receipts, Purchases (английские названия)
- Платежи и переводы, Оплата

### Поиск чеков

1. Нажмите кнопку "📅 Период" для выбора дат
2. Выберите период поиска (по умолчанию текущий месяц)
3. Нажмите "🔍 Найти чеки"
4. Дождитесь завершения поиска
5. Просмотрите результаты в таблице

### Быстрый выбор периода

В диалоге выбора периода доступны кнопки:
- **Текущий месяц** - с 1 числа текущего месяца до сегодня
- **Прошлый месяц** - весь прошлый месяц
- **Последние 7 дней** - неделя назад до сегодня

## Поддерживаемые форматы чеков

Приложение автоматически распознает чеки от следующих сервисов:

### Электронные кассы и ОФД
- Платформа ОФД (platformaofd.ru, chek.pofd.ru)
- OFD.ru (noreply@ofd.ru)
- Taxcom / Best2Pay
- СБИС

### Банки и платежные системы
- Сбербанк (ecom.sberbank.ru, SberPrime)
- ВТБ
- Тинькофф
- Альфа-Банк
- Газпромбанк
- Райффайзен

### Электронные кошельки
- YooMoney (бывший Яндекс.Деньги)
- QIWI
- WebMoney
- PayPal

### Другие сервисы
- Яндекс.Касса
- Paygine (Zerocoder и др.)
- Коммунальные услуги (Иркутскэнерго и др.)

Парсер использует паттерны для извлечения сумм в разных форматах:
- Рубли: `150.50 руб`, `250,75 рублей`, `1000.00 ₽`
- Безналичные: `БЕЗНАЛИЧНЫМИ 2.99`, `ИТОГ = 2.99`
- Иностранная валюта: `2.99 RUB`, `100.00 USD`
- Позиции чеков: `1 шт. x 2.99`, `1 X 207000.00 207000.00`

## Устранение неполадок

### Ошибка аутентификации
- Проверьте правильность email и пароля
- Убедитесь, что используется пароль для приложений (НЕ основной пароль!)
- Проверьте, что IMAP включен в настройках Mail.ru
- См. подробную инструкцию в [MAILRU_SETUP.md](MAILRU_SETUP.md)

### Нет подключения к серверу
- Проверьте подключение к интернету
- Убедитесь, что IMAP сервер доступен (imap.mail.ru:993)
- Проверьте настройки файервола/антивируса
- Попробуйте отключить VPN (если используется)

### Не найдены чеки
- **Папки Mail.ru**: Приложение автоматически проверяет INBOX и системные папки (Чеки, Покупки, Receipts и др.)
- Оставьте папку `INBOX` в настройках — поиск будет во всех нужных местах
- Убедитесь, что в письмах есть суммы денег и ключевые слова (чек, платеж, оплата)
- Попробуйте расширить период поиска
- Проверьте, что чеки пришли в указанный период
- Mail.ru может автоматически сортировать чеки в специальные папки
